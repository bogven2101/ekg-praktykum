# Як увімкнути розбір ШІ в Android-версії і на сайті

Потрібні: акаунт Anthropic (платний ключ API) і безкоштовний акаунт Cloudflare.

## 1. Ключ Anthropic
1. console.anthropic.com → зареєструйтеся → **Billing**: поповніть баланс (напр. $5–10).
2. **Limits → Spend limit**: поставте місячний ліміт (напр. $10) — це головний захист від перевитрат.
3. **API Keys → Create Key** → назва `ekg` → скопіюйте ключ (`sk-ant-...`). Він показується один раз.

## 2. Cloudflare Worker
1. dash.cloudflare.com → зареєструйтеся.
2. **Workers & Pages → Create → Create Worker** (шаблон «Hello World») → назва `ekg-ai` → **Deploy**.
3. **Edit code** → видаліть усе → вставте весь вміст файлу `worker/ekg-ai-worker.js` → **Deploy**.
4. Поверніться до воркера → **Settings → Variables and Secrets → Add**:
   - Type **Secret**, Name `ANTHROPIC_API_KEY`, Value — ключ `sk-ant-...`
   - Type **Secret**, Name `APP_TOKEN`, Value — значення `EKG_AI_TOKEN` з файлу `www/config.js`
   → **Deploy**.
5. Скопіюйте адресу воркера, вигляду `https://ekg-ai.ВАШ-ПІДДОМЕН.workers.dev`.

## 3. Підключити до застосунку
На GitHub відкрийте `www/config.js` → ✏️ (Edit) → у рядку `window.EKG_AI_URL = "";` вставте адресу воркера між лапками → **Commit changes**.
Збірка запуститься сама: через ~10 хв оновиться сайт і з'явиться новий .apk у Actions → Artifacts.
