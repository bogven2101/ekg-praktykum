# ЕКГ Практикум — як отримати Android-збірку, посилання і опублікувати в Google Play

Усе робиться в браузері, бажано на комп'ютері. Нічого встановлювати не потрібно.

## Що в цьому архіві
- `www/` — сам застосунок (працює офлайн) і сторінка політики конфіденційності `privacy.html`
- `android/` — Android-проєкт (Capacitor), назва «ЕКГ Практикум», ідентифікатор `ua.bogven.ekgpraktykum`
- `.github/workflows/build.yml` — автоматична збірка .aab/.apk і публікація сайту
- `store/` — іконка 512×512, банер 1024×500 і тексти для сторінки в Google Play

Ключ підпису надіслано **окремо** — не кладіть його в цей архів і на GitHub.

## Крок 1. Створити репозиторій на GitHub
1. Зареєструйтеся на github.com (безкоштовно).
2. Натисніть **+ → New repository**, назва: `ekg-praktykum`, тип **Public** (потрібно для безкоштовного сайту GitHub Pages), натисніть **Create repository**.

## Крок 2. Завантажити файли
1. Розпакуйте архів на комп'ютері.
2. У репозиторії натисніть **uploading an existing file** (або **Add file → Upload files**).
3. Перетягніть **вміст** розпакованої папки (папки `www`, `android`, `store`, `.github` і файли `package.json`, `package-lock.json`, `capacitor.config.json`, `.gitignore`, `ІНСТРУКЦІЯ.md`) → **Commit changes**.
4. Перевірте, що папка `.github/workflows` з'явилася. Якщо ні (деякі системи приховують папки з крапкою):
   **Add file → Create new file**, у полі імені введіть `.github/workflows/build.yml`, вставте вміст файлу `build.yml` з архіву → **Commit**.

## Крок 3. Додати ключ підпису (один раз)
**Settings → Secrets and variables → Actions → New repository secret**, створіть два секрети:
- `KEYSTORE_BASE64` — весь текст з файлу `KEYSTORE_BASE64.txt`
- `KEYSTORE_PASSWORD` — пароль з файлу `КЛЮЧ-ПІДПИСУ-ЗБЕРІГАТИ.txt`

## Крок 4. Увімкнути сайт
**Settings → Pages → Build and deployment → Source: GitHub Actions.**

## Крок 5. Запустити збірку
**Actions → «Збірка Android і сайту» → Run workflow** (далі збірка запускатиметься сама після кожної зміни файлів). Чекайте ~5–8 хвилин до зеленої галочки.
- **Android-файли:** відкрийте завершений запуск → внизу **Artifacts → EKG-Praktykum-1.0.N** → завантажиться zip з `app-release.aab` (для Google Play) і `app-release.apk` (можна встановити на телефон напряму).
- **Посилання на застосунок:** `https://ВАШ-ЛОГІН.github.io/ekg-praktykum/` — відкривається будь-кому, без входу в акаунти; на телефоні його можна «Додати на головний екран».
- **Політика конфіденційності:** `https://ВАШ-ЛОГІН.github.io/ekg-praktykum/privacy.html`

## Крок 6. Google Play
1. Акаунт розробника: play.google.com/console, одноразовий внесок $25, перевірка особи.
2. **Створити застосунок** → назва «ЕКГ Практикум», мова українська, «Застосунок», «Безкоштовно».
3. Заповніть розділи «Налаштування застосунку»:
   - **Політика конфіденційності** — посилання з кроку 5;
   - **Безпека даних** — «Застосунок не збирає і не передає дані»;
   - **Реклама** — немає; **Цільова аудиторія** — 18+;
   - **Застосунки для здоров'я** — позначте освітню/довідкову медичну категорію; застосунок не є медичним виробом;
   - **Рейтинг вмісту** — заповніть анкету.
4. **Сторінка в магазині** — тексти з `store/ОПИС-ДЛЯ-GOOGLE-PLAY.txt`, іконка `store/icon-512.png`, банер `store/feature-graphic-1024x500.png`, 2–8 скриншотів з телефона.
5. **Тестування → Закрите тестування** → створіть реліз, завантажте `app-release.aab`. Під час першого завантаження погодьтеся на **Play App Signing** (Google зберігає основний ключ, ваш — лише для завантаження).
6. **Якщо акаунт особистий і створений після 13.11.2023:** потрібно щонайменше 12 тестувальників, які 14 днів поспіль беруть участь у закритому тесті; лише після цього можна подати заявку на робочу версію (Production). Колеги з Android-телефонами — найпростіший варіант.

## Як випускати оновлення
Замініть `www/index.html` у репозиторії (Add file → Upload files) — GitHub сам збере нову версію з більшим номером. Завантажте новий `.aab` у Play Console.
